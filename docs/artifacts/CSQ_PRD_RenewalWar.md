## The moment this feature exists for

It is 7:45am. A CSM has a renewal call at 10am with an account that has been quiet for six weeks. The champion went on parental leave. The new contact hasn't responded to the last two emails. The contract is $180k. Their manager is going to ask about it in the 9am standup.

They open their laptop and have no idea where to start.

This is the moment The CS Quarterly needs to be open on their screen.

---

## What the feature does

The Renewal War Room is a pre-conversation preparation environment that activates when a CSM tells Lumi about an upcoming renewal. It does four things:

1. **Pre-call brief** — Lumi generates a structured, account-specific preparation document in under 60 seconds
2. **Live call companion** — during the call, the CSM can type real-time situation updates and Lumi responds with immediate tactical guidance
3. **Objection navigator** — a persistent panel of the most likely objections for this account type and how the P75 benchmark operators handle them
4. **Post-call debrief** — immediately after the call, Lumi captures what happened, updates the account context in Lumi Memory, and generates the next three actions

---

## Activation

Two entry points:

**Entry point 1 — Proactive (Future Operator)**
When `pending_renewal` in `future_operator_profiles` is within 7 days, the Future Operator sends a Drift Signal:
> *"Seven days to [account type] renewal. I know you have a plan. Let me help you stress-test it. Open the War Room."*
CTA: `[Open Renewal War Room]` → `/renewal-war-room?pre=true`

**Entry point 2 — Self-initiated**
Lumi bubble on the homepage shows: *"Preparing for a renewal? Lumi runs the War Room."*
User clicks → Lumi opens in War Room mode and asks: *"Tell me about the renewal — account type, contract value range, and what's making you most uncertain about this one."*

## Feature 1 — Pre-Call Brief

### Input
Lumi asks 5 questions in rapid sequence (conversational UI, not a form):

```
1. "What's the account profile — industry, ACV band, how long they've been a customer?"
2. "What's the renewal date and what's the current status of the relationship?"
3. "Who is in the room on their side — and who do you wish was there but won't be?"
4. "What's their most likely objection to renewing at current value?"
5. "What would a win look like beyond just getting the signature?"
```

### Output
A structured one-page brief generated by Lumi, rendered in the War Room workspace:

```

│                                                      │

│  [Lumi's read: what's really going on here,         │
```

## Feature 2 — Live Call Companion

### Activation
A **"I'm in the call now"** button at the top of the War Room. Clicking it shifts the UI into live mode — a clean, distraction-free layout optimised for typing fast while on a call.

### UI in live mode

```
┌─────────────────────────────────────────┐
│  ● LIVE  [Account type] renewal         │
│  ─────────────────────────────────────  │
│                                         │
│  [Brief collapsed — tap to expand]      │
│                                         │
│  OBJECTION PANEL (persistent sidebar)  │
│  · "Price too high" [tap for response] │
│  · "We're evaluating alternatives"     │
│  · "Champion is new, needs time"       │
│  · "ROI not clear to finance"          │
│                                         │
│  ─────────────────────────────────────  │
│  [Type what just happened...]           │
│  e.g. "CFO just joined unexpectedly"   │
│                                         │
│  Lumi responds in under 3 seconds      │
│                                         │
└─────────────────────────────────────────┘
```

### Live response behaviour
When the CSM types a situation update, Lumi responds with:
- **Immediate tactical guidance** (what to say or ask next)
- **No analysis** — live mode suppresses Lumi's explanatory register. Only action.
- **Under 40 words** — short enough to read while still on the call

Example:
> CSM types: *"CFO just joined and immediately asked about ROI data"*
> Lumi responds: *"Don't improvise the ROI number. Say: 'I want to give you the right figure — let me pull the exact data and send it within the hour.' This buys time and positions you as precise, not evasive."*

## Feature 3 — Objection Navigator

A persistent panel in the War Room (both pre-call and live) showing the 4 most likely objections for this account type, generated from:
- The CSM's answer to Q4 (their read on most likely objection)
- Benchmark data for this ACV band
- Lumi Memory (any objections mentioned in previous conversations)

Each objection card expands to show:
- The response the P75 operators use
- What not to say
- The follow-up question that changes the frame

---

## Feature 4 — Post-Call Debrief

Triggered when the CSM clicks **"Call ended"** in live mode.

Lumi asks 3 rapid questions:
```
1. "One word: how did it go?"
2. "What was the moment that mattered most — positive or negative?"
3. "What's the next action and when?"
```

Lumi then:
- Generates a structured call summary (saved to workspace)
- Updates `current_focus_account` and `current_biggest_risk` in `future_operator_profiles`
- Writes 3 memory entries to `lumi_memory`: what happened, what the next action is, what the CSM is feeling about the account
- Creates a Future Operator Drift Signal for 48 hours later referencing the next action

## Database additions

```sql
-- Renewal sessions: one per call preparation
CREATE TABLE renewal_war_room_sessions (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         uuid NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  
  -- Account context (anonymised — no company name collected)
  acv_band        text,
  industry        text,
  tenure_months   integer,
  renewal_date    date,
  
  -- Session state
  status          text DEFAULT 'prep' 
                  CHECK (status IN ('prep','live','debrief','complete')),
  
  -- Generated content
  pre_call_brief  jsonb,   -- the structured brief
  live_exchanges  jsonb[], -- array of {input, response, timestamp}
  post_call_summary jsonb, -- the debrief output
  
  -- Outcome tracking (optional, user-reported)
  outcome         text CHECK (outcome IN ('renewed','lost','extended','inconclusive')),
  
  created_at      timestamptz DEFAULT now(),
  updated_at      timestamptz DEFAULT now()
);

ALTER TABLE renewal_war_room_sessions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users manage own sessions"
  ON renewal_war_room_sessions FOR ALL TO authenticated
  USING (user_id = auth.uid());
```
